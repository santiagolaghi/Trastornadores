# Reina-Valera 1909

Texto de dominio público distribuido por [eBible.org](https://ebible.org/bible/details.php?id=spaRV1909). [Declaración de derechos](https://ebible.org/spaRV1909/copyright.htm). Se conserva el texto original, incluida su ortografía.

Los archivos JSON separan el VPL por libro, capítulo y versículo. El archivo `manifest.json` registra la fuente y su SHA-256. Esta edición es independiente de las traducciones que requieren licencia de YouVersion. No se almacena contenido de esas traducciones en estos archivos.

El VPL conserva posiciones vacías por diferencias de numeración de la edición. El lector omite esas posiciones vacías sin inventar texto; los capítulos mantienen el texto de la fuente.
